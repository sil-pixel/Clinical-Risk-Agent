# General-association retrieval benchmark — 16-source corpus

Research-only provisional result, run 2026-09-24. This is the requested comparison of **document** versus **hierarchical** indexing on the same Qdrant/PubMed-abstract corpus, using general association questions rather than paper-identifying prompts. It supersedes the 19-query report as the general-question comparison; that earlier run remains a source-lookup diagnostic.

| Macro metric (11 answerable questions) | Document | Hierarchical |
| --- | ---: | ---: |
| Precision@5 (grade-2 direct sources) | 0.036 | 0.127 |
| Recall@5 (grade-2 direct sources) | 0.182 | 0.636 |
| BERTScore F1@1, passage vs fixed reference answer | 0.690 | 0.715 |
| nDCG@5 (grades 2 direct, 1 context) | 0.097 | 0.253 |
| MRR@5 (first grade-2 direct source) | 0.045 | 0.156 |

Hierarchical placed a directly relevant publication within the first five for **7/11** answerable questions; document did so for **2/11**. The document ranking was nearly invariant across questions, prioritizing the same recent/high-tier sources. The retrieval implementation sorts selected candidates by evidence tier, recency, and quality before fused relevance, which likely suppresses query sensitivity. Hierarchical produces different candidate sets and fares better despite the same selection policy. This is a pipeline comparison, not a clean estimate of chunking's isolated causal effect.

The 11 answerable questions include five substance/genetics questions, two substance/ACE questions, one ACE-method context question, two bullying/depression context questions, and one genetics/PRS context question. The two no-direct-evidence probes ask about ADHD–substance-use disorder and bullying–substance-use disorder; neither has a direct source in this 16-paper corpus. They are **excluded** from the five answerable-query metric means. The retriever nonetheless returns papers for them; there is no calibrated abstention gate, so its answers must not claim these associations from this corpus. Bullying/depression hits cannot be counted as bullying/substance-use hits.

Scoring was predeclared in [`RAG_GENERAL_ASSOCIATION_GOLD_16_SOURCE.json`](RAG_GENERAL_ASSOCIATION_GOLD_16_SOURCE.json) before running retrieval. Each question has source-level grades: 2 = directly answers, 1 = useful context, 0 = not listed/not relevant. Precision, recall, and MRR count only grade 2. nDCG uses gain `2^grade - 1`. Scores are macro means at `k=5`; because most cases have one grade-2 publication, per-case Precision@5 has a ceiling of 0.2. BERTScore is the independent DistilBERT layer-5 contextual F1 of the **top-ranked exact retrieved passage** against a fixed assistant-authored reference answer; it is not a generated-answer score and does not validate correctness. In particular, its ~0.69–0.72 values remain high even when direct-source Recall@5 is zero.

Both runs used the same 16 PubMed abstracts, pinned MedCPT encoders, Qdrant BM25+dense RRF-60 retrieval, source cap, evaluation date, and a **predeclared diagnostic dense cosine threshold `>0.0`**. All 13 questions used the primary hybrid path, with no keyword fallback. This threshold is **not** the configured product gate `>0.85`; the prior diagnostic showed that gate drove every query to BM25 fallback. No cross-encoder reranker was pinned, so this benchmark has none. The BERTScore evaluator is `distilbert/distilbert-base-uncased` at revision `12040accade4e8a0f71eabdb258fecc2e7e948be`, weight SHA-256 `5e3f1108e3cb34ee048634875d8482665b65ac713291a7e32396fb18f6ff0063`, no IDF or baseline rescaling. Its general-domain model may misread biomedical nuance.

Reproduce with `MPLCONFIGDIR=/private/tmp HF_HUB_OFFLINE=1 PYTHONPATH=src .venv/bin/python scripts/rag_general_benchmark.py`. The ignored machine-readable result is `data/indexes/rag_general_benchmark_results.json`; the script validates the frozen gold, source manifest, indexed collections, and model hashes. The set is assistant-authored, not blindly dual-adjudicated. It is small, paraphrases reuse some sources, and both collections contain abstracts rather than licensed full text. This result supports continued hierarchical development, **not** clinical use or release selection.
